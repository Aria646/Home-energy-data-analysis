# Home Energy Data Analysis and Decision Support Platform

An interactive web application for household electricity cost simulation, peak/off-peak usage analysis, and personalised energy-saving recommendations.

## Overview

This project demonstrates how household appliance usage patterns can be translated into understandable electricity-cost and energy-consumption feedback. Users can configure appliance schedules, compare current and improved usage plans, and explore the effect of peak, shoulder, and off-peak tariff periods.

## Key Features

- Household appliance usage and schedule configuration
- Electricity cost and energy-consumption simulation
- Peak / shoulder / off-peak tariff analysis
- Current-plan and improved-plan comparison
- Energy-saving feedback and decision-support interface
- Responsive front-end interface built for interactive use
- Local user/record functionality for demonstration purposes

## Technologies

- HTML5
- CSS3
- JavaScript
- DOM-based interactive visualisation and interface logic
- Browser local storage / client-side functionality

## Portfolio Security Note

The original course/demo version contained an OpenAI API integration. No API credential is included in this public repository. AI-assisted features are intentionally disabled in the public static build because API keys must not be embedded in client-side code.

## Run Locally

Open `index.html` in a modern web browser, or serve the folder with a local static web server.
